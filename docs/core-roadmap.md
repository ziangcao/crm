## 下一阶段评估

2026-09-27 已完成部门数据范围的前后端、权限过滤、组织部门校验及回归验证。现有架构下，以下延后项不能以局部补丁安全复刻：

| 能力 | 评估结论 | 原因 |
| --- | --- | --- |
| 字段级权限 | 已验证 | 自定义角色可按模块将非必填字段设为隐藏或只读；目录、记录输出、搜索、导出、导入与 Agent Tool 均复用服务端强制校验，记录表单会禁用只读字段。 |
| 审批可视化设计器 | 已验证 | 画布复用既有审批步骤和条件模型，不改变执行语义。 |
| 动态表单布局、公式、子表 | 已验证 | 已定义持久化、服务端计算、逐行校验和统一导入导出模型。 |
| 可配置文档/PDF 模板 | 已验证 | 纯文本模板转义渲染并通过浏览器打印，不执行任意 HTML。 |
| 多级产品规格、库存扣减、拆单 | 已验证 | 库存变化与订单写入同事务并使用记录版本防冲突。 |

经本阶段代码、单测、静态检查和前端构建复核，P0 剩余项为零。字段级权限的隐藏、只读目录标记、表单禁用和服务端读写强制校验均已闭环；后续仅在明确业务规格后重新评估延后能力，不以局部前端控件替代领域模型。
