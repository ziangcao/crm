# CordysCRM 功能对照与后续范围

参考来源：
- https://github.com/1Panel-dev/CordysCRM
- https://github.com/1Panel-dev/CordysCRM/tree/main/frontend/packages/web/src/views
- https://raw.githubusercontent.com/1Panel-dev/CordysCRM/main/frontend/package.json

以下状态以本项目实际代码为准。“已实现”表示本项目中的基础业务可用，不表示上游所有细节已等价实现。

范围优先级和验收状态以 `docs/core-roadmap.md` 为准：`P0` 是继续复刻的必备能力；“延后”和“不复刻”不计入当前复刻完成度。

| 功能 | 本项目状态 | 当前范围 / 差异 |
| --- | --- | --- |
| 工作台 | 已实现 | 实际数据指标、六个月业绩趋势、任务、跟进、逾期回款 |
| 线索 | 已实现 | 增删改查、跟进、线索池、分配、转客户与联系人 |
| 客户 / 公海 | 已实现 | 客户分级、领取释放、负责人变更历史、关联业务同步转交；可通过 `CRM_CUSTOMER_RECYCLE_DAYS` 启用按闲置活动时间自动回收 |
| 联系人 | 已实现 | 关联客户、职位和决策角色 |
| 商机 | 已实现 | 可配置销售阶段、赢单概率、列表 / 看板 |
| 产品 | 已实现 | 目录、价格、编码、上下架、多级规格、可用与预占库存 |
| 报价 | 已实现 | 产品规格、折扣税率、Decimal 含税合计、审批、关联合同及可配置打印模板 |
| 合同 | 已实现 | 编号、客户、金额、期限、报价关联、审批 |
| 订单 | 已实现 | 产品明细、合同关联、审批、库存原子预占/释放/交付核销及草稿拆单 |
| 工商抬头 | 已实现 | 客户开票资料；无外部工商信息自动查询 |
| 发票 | 已实现 | 合同和抬头关联、审批、累计开票限制；无真实税务开票 |
| 回款计划 / 回款 | 已实现 | 合同/计划金额校验、审批后统计、逾期提示；无银行对账 |
| 标讯 | 已实现 | 人工登记、预算、截止日、投标状态；无自动标讯抓取 |
| 跟进与任务 | 已实现 | 跟进时间线、跟进记录/计划协作评论的创建、编辑、删除、方式、下次跟进日期、任务优先级和完成；跟进计划到期前 24 小时站内提醒与持久化去重；可通过 `CRM_CUSTOMER_RECYCLE_DAYS` 启用按闲置活动时间自动回收到公海。 |
| 审批 | 已实现 | 版本化、多级审批、金额/字段条件、撤回、转签、加签、历史及节点画布设计器 |
| 权限 / 成员 | 部分实现 | 保留管理员、经理、销售基础角色；支持组织内自定义角色的模块查看/维护权限、成员绑定、按请求实时鉴权、组织记录隔离、本人/本部门/下级部门/指定部门/全部数据范围，以及按模块隐藏或只读非必填字段。目录会标记只读字段并由表单禁用；字段规则在目录、记录输出、搜索、导出、导入与 Agent Tool 服务端执行；保留旧成员权限行为。提供默认预览、显式执行的旧数据组织归属工具。暂无上游完整权限点。 |
| 自定义字段 | 部分实现 | 支持文本、多行文本、数字、日期、邮箱、下拉、服务端公式求和和受控子表字段，以及字段分组排序和字段删除；无自由拖拽画布或通用表达式引擎。 |
| 导入导出 | 部分实现 | CSV 导出、CSV/XLSX/JSON 导入模板下载、服务端 CSV/JSON/XLSX 预览校验与原子导入及 OpenAPI 请求体说明、本项目旧数据组织归属工具；无上游迁移 |
| 操作日志 | 已实现 | 业务操作、账号变更、审批、导出审计及字段级前后差异 JSON |
| 通知 | 已实现 | 未读、审批通知、组织公告、SSE 实时刷新及企业微信外部投递 |
| HTTP / Agent Tool | 已实现 | REST、Cookie/API Key、Agent Tool、MCP JSON-RPC 与扩展 OpenAPI 页面 |
| 部署 | 已实现配置 | Go 单进程、GORM、PostgreSQL/MySQL 与 Docker Compose 持久卷；无集群部署 |
| 附件、文档模板 | 已实现 | 附件版本与权限管理、纯文本占位符模板、安全转义及浏览器打印 PDF |
| 移动端 | 部分实现 | 响应式 Web 支持可安装 PWA、独立窗口启动和应用壳离线缓存；业务数据、登录和写入仍需网络，无原生客户端。 |
| AI Agent / MCP / Skills | 部分实现 | 已预留记录、通知、跟进计划 Tool 适配，并支持用户 API Key 与 MCP JSON-RPC 供外部 Agent 继承用户权限；无模型服务、MCP Skills 和授权配置 |
| DataEase / 自助 BI | 已实现替代 | 内置按模块、分组维度、记录计数或数值汇总的权限内自助报表 |
| 企业微信 | 代码已实现 | 消息、OAuth、通讯录同步及模拟协议测试完成；真实凭据联调待部署环境。 |
| 飞书 / 钉钉 / SSO | 适配完成 | 环境变量配置、模拟模式、状态和真实端点连通性测试；生产授权待外部账号。 |
| 上游存量迁移 | 未实现 | 本项目 schema 独立，不能直接使用 CordysCRM 数据库 |

后续要达到“完整对齐”，应先确定上游固定版本和验收清单，再依次实施权限组织模型、审批设计器、自定义表单、文件体系、移动端、集成与迁移。当前不能标记为全面对齐完成。

部署本阶段变更前需执行现有 `backend/cmd/migrate`，为 `users` 和 `records` 增加组织/角色字段；本次未对运行中数据库执行迁移。
